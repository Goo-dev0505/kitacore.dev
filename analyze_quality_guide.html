01.

記事 #332 の問い

記事では「今この瞬間、その記事はまだ生きてるか？」を見るために2つの数式を提示した。 どちらも直近14日間の日次PVだけを見る、シンプルな設計。

記事の式 — 安定性Article #332
Stability = 10 / σ
σ = 直近14日の日次PVの標準偏差
ブレが小さいほど値が大きくなる。σ=0のとき上限10。
記事の式 — 資産スコアArticle #332
Score = V̄ × W × Stability
V̄ = 平均日次PV
W = 稼働した日数（PV増加日数）
3軸すべて高くないと上に行けない。
記事の設計思想： 「派手かどうかじゃなくて、毎日ちゃんと働いてるか」を見る。 一日だけバズった花火記事より、毎日地味に稼働するインフラ記事が高スコアになる構造。

03.

安定性の実装

記事の式Article #332
10 / σ
σ = 日次PVの標準偏差（絶対値）
毎日500PV の記事と毎日5PV の記事では σ の大きさが全然違う
スクリプトの式analyze_quality.py
1 / (1 + CV)
CV = σ / mean（変動係数）
平均で割ることでPV規模を消す。結果は必ず 0〜1 の範囲に収まる
🔍
なぜ CV を使うか — 具体例
記事A：毎日 200, 210, 190, 205, 195 PV → σ ≈ 7.9、CV ≈ 0.04 → 安定性 = 0.96
記事B：毎日 2, 3, 2, 3, 2 PV → σ ≈ 0.5、CV ≈ 0.2 → 安定性 = 0.83

10/σ だと記事A は 1.27、記事B は 20 — スケール差で逆転する。 CV ベースなら「ブレの割合」で比べるので公平。
analyze_quality.py — 安定性スコアの計算部分 
# PVが0より大きい日だけを対象にする（=稼働していない日を除外）
dpv_vals = grp["dpv"][grp["dpv"] > 0]

stability = None
if len(dpv_vals) >= 5:     # 5日以上の稼働実績がある記事だけ計算
    cv = float(dpv_vals.std() / dpv_vals.mean()) if dpv_vals.mean() > 0 else 99.0
    stability = round(1.0 / (1.0 + cv), 3)

# → 結果は 0〜1 の範囲。1.0 = 完全に毎日同じPVで超安定
観測対象：「全期間」の日次PVを使う。記事の直近14日とは違い、その記事が存在した全期間のブレを見る。 直近14日の「後期14日平均PV」とは別の指標として共存している。
04.

スコアの実装

記事の資産スコアは V̄ × W × Stability の掛け算。 スクリプトはここに「スキ率」と「持続率」を加え、sigmoid正規化した加重平均に変えた。

質スコア（0〜100点）— analyze_quality.py
sigmoid(スキ率) × 40%  ＋  sigmoid(持続率) × 35%  ＋  sigmoid(安定性) × 25%
軸重み意味sigmoid パラメータ
スキ率40%累計スキ ÷ 累計PV × 100。「読者に刺さったか」center=3.0, scale=2.0
持続率35%後期平均PV ÷ 初速7日平均。「長く読まれ続けているか」center=0.2, scale=0.15
安定性25%1/(1+CV)。「コンスタントに読まれているか」center=0.3, scale=0.2
analyze_quality.py — 質スコア計算 
def sigmoid_norm(x, center, scale):
    """値を 0〜1 に正規化する。center 付近で 0.5 になる S字カーブ"""
    if x is None or (isinstance(x, float) and np.isnan(x)):
        return None
    return float(1 / (1 + np.exp(-(x - center) / scale)))

def calc_quality_score(eta: float, longevity, stability) -> float:
    # 各軸を sigmoid で 0〜1 に正規化
    s_eta       = sigmoid_norm(eta,       center=3.0,  scale=2.0)  or 0.0
    s_longevity = sigmoid_norm(longevity, center=0.2,  scale=0.15) if longevity is not None else 0.5
    s_stability = sigmoid_norm(stability, center=0.3,  scale=0.2)  if stability is not None else 0.3

    # 加重平均して 0〜100 にスケール
    score = (s_eta * 0.40 + s_longevity * 0.35 + s_stability * 0.25) * 100
    return round(score, 1)
💡
sigmoid を挟む理由
スキ率 20% の記事とスキ率 3% の記事を単純に掛け算すると差がつきすぎる。 sigmoid は「閾値を超えると急速に評価が上がり、それ以上は頭打ちになる」S字カーブ。 center=3.0 はスキ率3%前後で評価が分かれるライン、という設定。
質スコアを構成する全指標
スキ率（%）
累計スキ ÷ 累計PV × 100。最終時点の値
スキ率トレンド（pp）
後期スキ率 − 初期スキ率。+なら後から評価が上がった記事
持続率
後期平均PV ÷ 初速7日平均。1.0なら初速と同じペースを維持
安定性スコア
1/(1+CV)。全期間の日次PVの変動係数の逆数
後期14日平均PV
最新14日間の日次PV平均。「今の稼働力」
ハーフライフ（日）
ピーク後、日次PVが半減するまでの日数。息の長さ
05.

成長タイプ分類

記事の「花火 vs インフラ」を、7種類の成長パターンに細分化した。 obs_delay ≤ 3（投稿当日〜3日以内から追跡開始している記事）のみ詳細分類できる。 それ以外は初速が不明なため、「直近14日の稼働力」で判定する。

🎆
バースト型
初速 > 中期avg × 3
記事の「花火記事」そのもの。公開直後だけ読まれて急落。
🌲
定常型
後期avg ≥ 初速avg × 0.5
記事の「インフラ記事」。後期が初速の50%以上を維持し続ける。
🌱
遅咲き型
後期avg > 初速avg × 1.2
記事にはなかった分類。時間とともに発見され、後から伸びる。
📉
フェード型
後期データあり・定常でない
一時的に読まれたが定着しなかった。バースト未満の失速。
🌙
スリーパー型
初速不明 ＋ 後14日avg ≥ 1.0
古くて初速不明だが今も読まれている。記事の「静かに働く記事」。
💤
眠り型
初速不明 ＋ 後14日avg < 1.0
初速不明かつ今もほぼ動いていない。リライト候補。
📊
成長中
obs_delay ≤ 3 ＋ 後期データ未到達
投稿から31日未満でまだ後期に達していない若い記事。
分類の前提： 成長タイプの詳細分類（バースト/定常/遅咲きなど）は、投稿日から3日以内に追跡開始できた記事（obs_delay ≤ 3）のみ有効。 それ以外は初速PVが計算できないため、スリーパー型または眠り型に分類される。 にーやんのデータでは約173件がこの条件を満たしている。

scripts/analyze_quality.py — 全文（コピペしてそのまま動く） 
#!/usr/bin/env python3
"""
analyze_quality.py  —  note 記事の「質」を多角的に解析する

使い方:
  python scripts/analyze_quality.py \
      --articles data/articles.csv \
      --out data/
"""

import argparse
import logging
import sys
from datetime import date
from pathlib import Path

import numpy as np
import pandas as pd

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
    datefmt="%H:%M:%S",
)
log = logging.getLogger(__name__)

TODAY = pd.Timestamp(date.today())


def parse_args():
    p = argparse.ArgumentParser(description="記事品質解析エンジン")
    p.add_argument("--articles", required=True, help="articles.csv のパス")
    p.add_argument("--out", default="data/", help="出力ディレクトリ")
    p.add_argument(
        "--min-obs-days", type=int, default=7,
        help="最低観測日数（これ未満はスキップ）"
    )
    return p.parse_args()


def to_naive(ts):
    if pd.isna(ts):
        return pd.NaT
    return ts.tz_convert("UTC").replace(tzinfo=None) if ts.tzinfo else ts


def sigmoid_norm(x, center, scale):
    if x is None or (isinstance(x, float) and np.isnan(x)):
        return None
    return float(1 / (1 + np.exp(-(x - center) / scale)))


def analyze_article(key: str, grp: pd.DataFrame) -> dict:
    grp = grp.sort_values("date").reset_index(drop=True)

    latest       = grp.iloc[-1]
    title        = str(latest.get("title", key))
    total_pv     = float(latest["read_count"])
    total_like   = float(latest["like_count"]) if pd.notna(latest.get("like_count")) else 0.0
    total_comment = float(latest["comment_count"]) if pd.notna(latest.get("comment_count")) else 0.0

    pub_raw  = grp["published_at"].dropna().iloc[0] if grp["published_at"].notna().any() else pd.NaT
    pub      = to_naive(pub_raw)
    obs_days = grp["date"].nunique()
    first_obs = grp["date"].iloc[0]
    age      = int((TODAY - pub).days)      if pd.notna(pub) else None
    obs_delay = int((first_obs - pub).days) if pd.notna(pub) else None

    # 日次PV（累計差分・非負クリップ）
    grp["dpv"] = grp["read_count"].diff().fillna(0.0).clip(lower=0.0)
    if pd.notna(pub) and obs_delay == 0:
        grp.at[0, "dpv"] = float(grp.at[0, "read_count"])

    grp["dpv_ma"] = grp["dpv"].rolling(3, min_periods=1).mean()
    grp["ddays"]  = (grp["date"] - pub).dt.days if pd.notna(pub) else range(len(grp))

    # スキ率
    eta_final = round(total_like / total_pv * 100, 2) if total_pv > 0 else 0.0

    # スキ率トレンド（前1/3 vs 後1/3）
    grp["eta_row"] = grp["like_count"].fillna(0) / grp["read_count"].replace(0, np.nan) * 100
    n   = len(grp)
    seg = max(n // 3, 1)
    eta_early_mean = grp["eta_row"].iloc[:seg].mean()
    eta_late_mean  = grp["eta_row"].iloc[-seg:].mean()
    eta_trend = round(float(eta_late_mean - eta_early_mean), 2) \
        if pd.notna(eta_early_mean) and pd.notna(eta_late_mean) else None

    # 後期14日平均PV
    late14_avg = round(float(grp["dpv"].tail(14).mean()), 2)

    # 安定性スコア（CV ベース）
    dpv_vals  = grp["dpv"][grp["dpv"] > 0]
    stability = None
    if len(dpv_vals) >= 5:
        cv = float(dpv_vals.std() / dpv_vals.mean()) if dpv_vals.mean() > 0 else 99.0
        stability = round(1.0 / (1.0 + cv), 3)

    # 成長パターン（obs_delay ≤ 3 の記事のみ計算）
    initial_7d = peak_dpv = days_to_peak = half_life = None
    mid_avg = late_avg = longevity = None
    can_measure = (pd.notna(pub) and obs_delay is not None and obs_delay <= 3)

    if can_measure:
        early_rows = grp[grp["ddays"] <= 7]
        mid_rows   = grp[(grp["ddays"] > 7)  & (grp["ddays"] <= 30)]
        late_rows  = grp[grp["ddays"] > 30]

        initial_7d = int(early_rows["dpv"].sum()) if not early_rows.empty else None

        if not grp["dpv_ma"].empty:
            peak_idx_loc = int(grp["dpv_ma"].idxmax())
            peak_dpv     = int(round(grp.at[peak_idx_loc, "dpv_ma"]))
            days_to_peak = int(grp.at[peak_idx_loc, "ddays"])
            after_peak   = grp[grp["ddays"] >= days_to_peak]
            half_rows    = after_peak[after_peak["dpv_ma"] <= peak_dpv * 0.5]
            if not half_rows.empty:
                half_life = int(half_rows.iloc[0]["ddays"]) - days_to_peak

        mid_avg  = round(float(mid_rows["dpv"].mean()), 1)  if not mid_rows.empty  else None
        late_avg = round(float(late_rows["dpv"].mean()), 1) if not late_rows.empty else None
        early_avg_7d = (initial_7d / 7.0) if initial_7d else None
        if early_avg_7d and early_avg_7d > 0 and late_avg is not None:
            longevity = round(late_avg / early_avg_7d, 3)

    gtype   = classify_growth_type(obs_delay, obs_days, can_measure,
                  initial_7d, mid_avg, late_avg, longevity, late14_avg, total_pv)
    quality = calc_quality_score(eta_final, longevity, stability)

    return {
        "集計日":             TODAY.date().isoformat(),
        "key":                key,
        "タイトル":           title,
        "Age":                age,
        "観測遅延日数":       obs_delay,
        "観測日数":           obs_days,
        "累計PV":             int(total_pv),
        "累計スキ":           int(total_like),
        "コメント数":         int(total_comment),
        "スキ率(%)":          eta_final,
        "スキ率トレンド(pp)": eta_trend,
        "後期14日平均PV":     late14_avg,
        "初速PV(7日)":        initial_7d,
        "ピーク日次PV":       peak_dpv,
        "ピーク到達日数":     days_to_peak,
        "ハーフライフ(日)":   half_life,
        "中期平均PV":         mid_avg,
        "後期平均PV":         late_avg,
        "持続率":             longevity,
        "安定性スコア":       stability,
        "成長タイプ":         gtype,
        "質スコア":           quality,
    }


def classify_growth_type(
    obs_delay, obs_days, can_measure,
    initial_7d, mid_avg, late_avg, longevity,
    late14_avg, total_pv
) -> str:
    if obs_days < 10:
        return "❓ データ不足"
    if can_measure:
        early_avg = (initial_7d / 7.0) if initial_7d else None
        if late_avg is not None and early_avg and late_avg > early_avg * 1.2:
            return "🌱 遅咲き型"
        if late_avg is not None and early_avg and late_avg >= early_avg * 0.5:
            return "🌲 定常型"
        if mid_avg is not None and mid_avg > 0 and early_avg and early_avg > mid_avg * 3:
            return "🎆 バースト型"
        if late_avg is not None:
            return "📉 フェード型"
        return "📊 成長中"
    else:
        if late14_avg >= 1.0:
            return "🌙 スリーパー型"
        elif late14_avg >= 0.1 and total_pv >= 200:
            return "💤 眠り型"
        return "❓ データ不足"


def calc_quality_score(eta: float, longevity, stability) -> float:
    s_eta       = sigmoid_norm(eta,       center=3.0,  scale=2.0)  or 0.0
    s_longevity = sigmoid_norm(longevity, center=0.2,  scale=0.15) if longevity is not None else 0.5
    s_stability = sigmoid_norm(stability, center=0.3,  scale=0.2)  if stability is not None else 0.3
    score = (s_eta * 0.40 + s_longevity * 0.35 + s_stability * 0.25) * 100
    return round(score, 1)


def main():
    args = parse_args()

    df = pd.read_csv(args.articles)
    df["date"]         = pd.to_datetime(df["date"])
    df["published_at"] = pd.to_datetime(df["published_at"], utc=True, errors="coerce")

    keys = df["key"].unique()
    log.info("記事数: %d", len(keys))

    records, skipped = [], 0
    for key in keys:
        grp = df[df["key"] == key]
        if grp["date"].nunique() < args.min_obs_days:
            skipped += 1
            continue
        records.append(analyze_article(key, grp))

    log.info("解析完了: %d 記事 (スキップ %d)", len(records), skipped)

    out_df = (
        pd.DataFrame(records)
        .sort_values("質スコア", ascending=False)
        .reset_index(drop=True)
    )

    out_path = Path(args.out) / "article_quality.csv"
    out_path.parent.mkdir(parents=True, exist_ok=True)
    out_df.to_csv(out_path, index=False, encoding="utf-8-sig")
    log.info("保存: %s (%d 行)", out_path, len(out_df))


if __name__ == "__main__":
    main()
