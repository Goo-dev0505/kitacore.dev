01. What it is

このツールは何をするもの？

キャラクター設計や画像生成向けの文章を、 「何を作りたいか」→「どう見せたいか」→「避けたいもの」 の順で整理して、完成プロンプトにまとめるツールです。

  • 長文プロンプトが苦手でも使いやすい
  • テンプレから始められる
  • 書き直しより「追記」で進めやすい
  • ローカルで完結するので扱いが軽い
02. Best for

向いている人

  • まずは簡単に形にしたい人
  • プロンプトをゼロから書くのがしんどい人
  • ChatGPTや画像生成AIに貼る文章を整えたい人
  • 重たい設計画面より、軽い実用版がほしい人
03. Quick start

最短の使い方

1

テンプレを選ぶ

最初はテンプレかサンプル投入から始めるのがおすすめです。空欄から全部埋める必要はありません。

2

必要な項目だけ入れる

テーマ、雰囲気、髪、目、衣装、光、ネガティブなど、重要なところだけ追記します。

3

右側の完成文を確認

入力に応じて自動で完成プロンプトが更新されます。全体の流れが崩れていないかを見るだけでOKです。

4

コピーして使う

完成したら コピー を押して、そのままChatGPTや画像生成AIへ貼り付けます。

04. Input fields

入力欄の意味

テーマ
何を作りたいか。ざっくり1文で十分です。例：近未来の女性キャラを作りたい。
目的
何のために使うか。例：画像生成AIに貼る、キャラ案を固める、サムネ用に整える。
世界観 / 雰囲気
全体の空気感を決める欄です。ここが土台になります。
顔まわり
髪、目、表情など。キャラの印象が出やすいので優先度高めです。
衣装 / 全身
服、体格、立ち姿。全身まで伸ばしたいときに入れます。
光 / 背景
見た目の完成度に効く欄です。迷ったら「soft light」「minimal background」でも十分です。
避けたい表現
崩れやすい点を先に止める欄です。例：extra fingers, messy anatomy, cluttered background。
05. Buttons

ボタンの役割

  • コピー：今表示されている完成プロンプトをコピーします
  • サンプル投入：例文を一気に入れます
  • クリア：入力内容を空にします

Lite版は、あえて機能を絞っています。 「保存形式をいろいろ選ぶ」「YAMLやJSONでも見る」みたいな複雑さは削ってあります。

06. Auto save

入力は自動で残る

このツールはブラウザのローカル保存を使って、入力内容を自動で残します。 同じブラウザで開き直すと、前回の内容が残ることがあります。

  • 残したくないときは クリア を使う
  • 別テーマで作るときも、最初にクリアすると混ざりにくい
07. Recommended workflow

おすすめの流れ

  • 最初はサンプルを入れる
  • そこから「髪」「目」「衣装」だけ変える
  • 次に「世界観」と「ネガティブ」を足す
  • 最後に完成文をコピーしてAIへ貼る

つまり、Lite版は「設計する」よりも「まず使える形にする」ための版です。

08. Tips

うまく使うコツ

  • 全部埋めなくていい。重要な3〜5項目だけでも動きます
  • 世界観は文章、細部は単語で入れると整いやすいです
  • 崩れやすいときほどネガティブ欄を先に入れるのが有効です
  • 同じキャラを量産したいなら、世界観を固定して髪・表情・衣装だけ変えると使いやすいです
09. FAQ

よくあるつまずき

Q. 空欄があっても使える？

使えます。Lite版は、全部埋めることより「まず完成文を出す」ことを優先しています。

Q. どこから触ればいい？

サンプル投入 → テーマ変更 → 髪と目を修正、が一番ラクです。

Q. 元の高機能版との違いは？

Lite版は、分岐と設定項目を減らして初見でも迷いにくくしています。

Q. 本格運用もできる？

できます。ただし細かい構造管理や複数出力が必要なら、上位版の方が向いています。

Character Prompt Builder Lite 用の単体HTML取説。ローカル保存の挙動はブラウザ依存です。配布する場合は、Lite本体HTMLとこの取説HTMLを同じフォルダに置くのがおすすめです。
