🖥
v1 — はじまり

スマホでURLを開くだけに
準備ゼロ、リンクを開けばすぐ使える。デッキ（カード集CSV）はスマホから読み込めて、一度読めば次から自動で復元されます。

v3の新機能、こんなときに

✂️
よく使う札だけの「マイデッキ」を作りたい
大きいデッキから、ファンタジー系だけ・背景だけ、のように好きなまとまりを選んで小さなデッキに切り出せます。
🎴 DECK → 🛠 デッキ工房 → 読み込み中のデッキから作る
✏️
いらない札を消したい・呪文をちょっと直したい
デッキの中身を一覧で見ながら、検索して、消したり書き直したり足したり。保存すれば次に開いたときもそのまま。
🎴 DECK → ✏ デッキ編集
📝
ためてたお気に入りフレーズをデッキにしたい
「日本語名と英語フレーズ」のメモや表を貼り付けるだけでカードになります。エクセルもプログラミングも不要。
🎴 DECK → 🛠 デッキ工房 → 単語リストから変換
💾
作ったデッキを残したい・友達と交換したい
工房・編集で作ったデッキはCSVファイルとして保存できます。ファイルを渡せば、相手も同じデッキで遊べます。
各画面の「⬇ CSVを保存」
04

よくある質問

いま持っているデッキは v3 でも使える？
使えます。デッキのファイル形式はv2とv3で共通なので、買ったデッキも自作デッキもそのまま読み込めます。
v3にするのに何か設定はいる？
いりません。v3のURLを開いて、いつものデッキを読み込むだけです。
デッキ編集で失敗したら元に戻せる？
「保存」を押すまでは盤面に反映されないので、閉じればなかったことにできます。また、元のCSVファイルが手元に残っていればいつでも読み直せます。大事なデッキはCSVを取っておくのがおすすめです。
難しい知識は必要？
不要です。v3の新機能はぜんぶ画面のボタン操作だけで完結します。表計算アプリすら使いません。
v1やv2はもう使えなくなる？
使えます。ただv3はv2でできることを全部含んでいるので、特別な理由がなければv3がおすすめです。
