The Core Shift
いちばん大きな変化は「データを本体から切り離した」こと
ノーマル：JSに直書き
const PROMPT_DATA = [...] → ＋：CSVに外部化
（v1で実施） → V2：差し替え可能な
デッキ＝商品に

ノーマルは約244件のカードがコードに埋まっていて、辞書を変えるには本体HTMLを直接いじる必要があった。＋系（v1でCSV化 → v2で二層構造化）以降は「辞書だけ作る・更新する・売る」が可能になり、これがフリーミアム事業の前提になっている。UI・盤面・スロット構成といった操作面はノーマルからほぼそのまま継承。

03WHAT CHANGED, VERSION BY VERSION
NORMAL ポン出しビルダー（無印） baseline

出発点。素材カードが本体HTMLのJSに直書きされた一体型ツール。サーバ不要で自己完結する代わりに、辞書を変えるには本体そのものを編集するしかなかった。

📦データ内蔵
約244件のカードを const 配列でコードに同梱
🎛盤面UI
スロット式の選択UI・ネガティブ・パラメータ（以降に継承）
🔒固定辞書
差し替え・記憶・拡張の概念なし
v2.0 二層構造化 ＝ 商品化の土台 ＋ の本命

データを本体から切り離し、「空の盤面（エンジン層）＋差し替え可能なデッキCSV（データ層）」に再設計（CSV外部化自体はv1で先行実施）。辞書を商品として配れる構造になった世代。

🗂二層構造
盤面は公開、デッキは別配布の商品に分離
📂デッキ読込
UIから端末内CSVを選択・複数同時読込
💾端末記憶
一度読んだデッキを記憶し次回自動復元
➕無改修拡張
cat_label / slot 列で新カテゴリ・スロット追加
🔐ローカル完結
CSVは外部送信ゼロ・サーバ不要の単一HTML
引き継ぎ：盤面UI・ネガティブ・パラメータはノーマルからほぼそのまま。v1の data/ 自動読込も互換維持。
v3.0 デッキ工房（Deck Forge）内蔵 作る側の機能

v2.0の盤面はそのままに、デッキを自作・変換・編集する機能をブラウザ内に内蔵。既存のHTMLプロンプトビルダーや単語リストを「検証済みデッキCSV」に変換できる。

🛠デッキ工房
HTMLのJS配列／単語リスト → 確認UI → CSV出力
✂️切り出し
読込中デッキを読込元×カテゴリ単位で新デッキ化
✏️デッキ編集
カード単位で追加・修正・削除（検索・絞り込み付き）
✅内蔵バリデータ
validate_csv.py 同等の検査。ERRORは出力不可
🛡安全変換
変換元HTMLは実行せずテキスト解析のみ・外部送信なし
引き継ぎ：盤面・デッキ管理・キャッシュ・サンプルデッキ・CSVスキーマはv2.0から無改修。
v3.1 プリセット保存・復元 2026-06

v3.0に、作りかけのプロンプトを丸ごとJSONに保存して完全復元する機能を追加。手直しした完成本文まで含めて、後から続きを編集できる。

💾プリセット保存
名前・選択カード・ネガ・ツール・パラメータ・完成本文をJSON化
📥完全復元
読込で盤面の状態と手直し本文をそのまま復元
🃏カスタムカード同梱
プリセット内に埋め込み、別端末でも復元可
⚠️欠損検出
未読込デッキのカードはスキップしトーストで通知
🔎形式検証
type:"kitacore-prompt-preset" で検証・不正JSONは弾く
引き継ぎ：デッキ工房・デッキ編集・盤面はv3.0と同じ。プリセット保存は「カスタムカード書き出し（辞書のバックアップ）」とは別機能。
