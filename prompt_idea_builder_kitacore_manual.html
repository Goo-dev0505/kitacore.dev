MANUAL · PROMPT BUILDER SERIES

Prompt Idea
Builder. 取扱説明書

画像生成AI向けプロンプトを選択式でつくる、KITAcoreのビルダーツールの使い方ガイドです。ChatGPT Images / Midjourney / Nano Banana に対応した 90本超のテンプレを3ステップで操作できます。

01

ツール概要

Prompt Idea Builder は、画像生成AIに渡すプロンプトをテンプレート選択式で素早く組み立てるためのシングルファイルHTMLツールです。

📋

テンプレ選択式

90本超のプロンプトを収録。カテゴリ・検索で絞り込んで即選択できます。

✏️

差し込み項目

{{ }} 形式の変数が自動的に入力フォームになります。

⚙️

共通オプション

アスペクト比・出力先・文字あり/なし・添付画像の使い方を全テンプレに適用。

📤

即コピー

完成プロンプトをワンクリックでコピー。そのまま貼り付けて使えます。

🎯

4ツール対応

ChatGPT Images / Midjourney / Nano Banana / Pollo AI 向けに出力を最適化。

📁

TXT保存

完成プロンプトをテキストファイルとして手元に保存できます。

対応ツール ChatGPT Images、Midjourney、Nano Banana（画像生成AI汎用）、Pollo AI の4つに対応しています。共通オプションの「出力先」で切り替えることで、ツールごとに最適化したプロンプトを生成します。
02

クイックスタート — 5ステップ

初めて使う場合はこの手順に沿って操作してください。慣れれば2〜3分でプロンプトが完成します。

1
カテゴリを選ぶ

画面左パネルの上部チップ（「すべて」「サムネ」「広告」など）から目的のカテゴリを押してフィルタリングします。

2
テンプレカードを選択する

テンプレ一覧からカードを1枚クリックします。右側（Step02）の入力欄が切り替わります。

3
差し込み項目を埋める

「差し込み項目」セクションに表示されたフィールドに、テーマ・タイトル・業種など具体的な言葉を入力します。

4
共通オプションを調整する（任意）

アスペクト比・出力先・画像内文字・添付画像の使い方を必要に応じて変更します。指定なしの場合はテンプレ側の設定が優先されます。

5
「プロンプト更新」→「コピー」

黒い「プロンプト更新」ボタンを押すと右パネルに完成プロンプトが表示されます。「コピー」ボタンでクリップボードに転送して完了です。

TIP テンプレの「ヒント」カテゴリには、ロゴ・スライド・フォント作成のコツがまとめられています。使い始めに一度読んでおくと品質が上がります。
03

画面レイアウト

ツールは3カラム構成です。左から「Step01 テンプレ選択」→「Step02 入力・調整」→「Step03 完成プロンプト」の順に操作します。

04

Step 01 — テンプレを選ぶ

左パネルでテンプレートを絞り込み・選択します。3つの操作方法があります。

検索ボックス

フリーワードで全テンプレのタイトル・カテゴリ・プロンプト本文を横断検索できます。

検索ヒント 「広告」「サムネ」「ロゴ」「SaaS」「Z世代」「フォント」などキーワードを入力してください。カテゴリ名でも絞り込めます。

カテゴリチップ

カテゴリボタンを押すと該当するテンプレのみ表示されます。もう一度押すか「すべて」を押すとリセットされます。

すべて 94 クイック例 6 広告 6 サムネ 13 ロゴ 16 スライド 31 フォント 5 イラスト 6 その他 5 ヒント 3

テンプレカードの見方

要素内容
タイトル（太字） テンプレの名前。「バナー広告」「ミニマル・上品」「SaaS企業風」など。
概要テキスト プロンプト冒頭の100字程度のプレビュー。内容の確認に使う。
タグ カテゴリと差し込み項目名のバッジ。選択前に必要な入力項目を確認できる。
左ボーダー（青） 現在選択中のカードにのみ表示される青いアクセントライン。
05

Step 02 — 入力して調整する

テンプレを選択すると中央パネルが切り替わり、そのテンプレ専用の入力欄が出現します。

テンプレ概要プレビュー

パネル上部にグレーのプレビューボックスが表示され、選択中テンプレのカテゴリ・タイトル・プロンプト冒頭が確認できます。

差し込み項目（動的フォーム）

テンプレ内の {{ }} 記法で囲まれた変数が自動的に入力フォームになります。フォームに入力した値が、プロンプト更新時に対応する変数と入れ替わります。

フィールド名入力内容入力のコツ
タイトル 記事・画像のタイトル文字列 例：「AI時代の創作ログ」
サブタイトル サブ見出し・キャッチコピー 例：「道具と遊び方を整理する」
商材 広告対象の商品・サービス名 例：「実践型AI活用講座」
ターゲット 想定する読者・購買者 例：「AIを仕事に取り入れたいビジネスパーソン」
メインコピー 広告の主文（キャッチコピー） 例：「AIを、使える武器に。」
CTA 行動促進テキスト 例：「詳しく見る」「今すぐ始める」
ブランド名 ブランド・サービス名 例：「KITAcore Lab」
業種 業種カテゴリ 例：「化粧品」「SaaS」「フィットネス」
ジャンル コンテンツジャンル 例：「VTuber」「カフェ」「フィンテック」
枚数 生成枚数 例：「6」「12」「24」
種類数 バリエーション数（フォント・スタンプ等） 例：「16」「24」「40」
比率 アスペクト比 例：「3:4」「1:1」「16:9」
テーマ スライドやコンテンツのテーマ 例：「投資家向けIR資料」「推し活コミュニティ」
文字 フォント作成の対象文字 例：「あ」「A」「KIT」
モチーフ スタンプ・図解のモチーフ 例：「動物」「食べ物」「家電キャラ」
TIP — 空欄のまま更新するとどうなる？ 差し込み項目を空欄のまま「プロンプト更新」を押すと、{{フィールド名}} という変数記法がそのままプロンプトに残ります。あとでテキストエリア内を直接編集することもできます。

元テンプレを直接編集する（上級）

「元テンプレを直接編集する」という折りたたみエリアを開くと、テンプレのプロンプト本文を直接書き換えられます。{{新しい変数名}} を追加すれば、差し込み項目として自動認識されます。

06

Step 03 — 完成プロンプト

右パネルに完成プロンプトが表示されます。このテキストをそのまま画像生成AIに貼り付けて使います。

出力テキストエリア

プロンプト全文が表示される大きなテキストエリアです。「プロンプト更新」ボタンで内容が更新されます。テキストエリアを直接クリックして手動で細かく編集することもできます。

ヘルパーテキスト

テキストエリア下部に、選択中テンプレの使い方ヒントや対応ツールの補足が表示されます（一部テンプレのみ）。

スペルチェックについて 出力テキストエリアはスペルチェック（赤波線）が無効になっています。英語プロンプトが多いため、誤検出を防ぐための設定です。

08

共通オプション — 全6項目

差し込み項目の下に表示される共通オプションは、テンプレに関わらず全プロンプトに適用される追加条件です。

フィールド選択肢・入力内容使い方
アスペクト比 16:9 / 1.91:1（noteサムネ）/ 1:1 / 4:5 / 3:4 / 9:16 / 4:3 テンプレ指定がある場合はそちら優先。上書きしたいときに選択する。
出力先 ChatGPT Images / Midjourney向け / Nano Banana汎用 / Pollo AI用 使用するAIに合わせて選択。プロンプトの末尾に対応する指示が追加される。
画像内文字 テンプレ指定優先 / 文字あり / 文字なし / タイトルのみ ロゴや背景素材など文字不要の場合は「文字なし」を選ぶ。
添付画像の使い方 指定なし / 雰囲気と構図を活かす / キャラクターを維持 / ロゴ素材を入れ込む / 色味だけ参考 参照画像を添付するときに用途を明示する。指定なしでは添付画像は無視される。
クイック入力 テーマ・タイトル・ブランド名など自由入力 差し込み項目に相当する情報をまとめて一行で書ける。テンプレ側の変数とは別に末尾に追記される。
追加条件 自由テキスト（テキストエリア） 「黒×グレー、余白多め」「SNSで目立つ」など補足条件を書く。プロンプト末尾に連結される。
避けたい表現 自由テキスト（テキストエリア） 「文字崩れ、低解像度」など生成AIに避けてほしい表現を明記する。ネガティブプロンプトに相当。
TIP — 「クイック入力」と「差し込み項目」の違い 差し込み項目はテンプレの {{変数}} と1対1で置換されます。クイック入力はプロンプト末尾に一文として追記されます。どちらも使うと、より細かくコントロールできます。
09

アクションボタン

Step02パネルの下部に4つのボタンが並んでいます。

ボタン動作備考
プロンプト更新（黒） 差し込み項目・共通オプションの内容を反映して右パネルのプロンプトを再生成する。 入力変更後は必ず押す。
コピー 完成プロンプトをクリップボードにコピーする。画面右下に「コピーしました」トーストが表示される。 更新後すぐ使えます。
TXT保存 完成プロンプトを .txt ファイルとしてダウンロードする。 プロンプトを手元に残したいときに使う。
入力リセット（ゴースト） 差し込み項目と共通オプションの入力をすべて空欄に戻す。 テンプレ自体は変わらない。
10

使い方パターン

よくある使い方を目的別にまとめました。

A

note記事のサムネを作る

カテゴリ「サムネ」でフィルタリング → スタイルを選ぶ（高級感、テック系、韓国デザインなど）→ タイトルとサブタイトルを入力 → アスペクト比「1.91:1（noteサムネ）」を選択 → プロンプト更新 → コピー → ChatGPT Imagesに貼り付け。

B

広告クリエイティブを4サイズ生成する

カテゴリ「広告」→「汎用プロンプト」を選択 → 商材・ターゲット・訴求・メインコピー・CTA・ブランド名を入力 → 出力先は ChatGPT Images → プロンプト更新 → コピー。4サイズ分のクリエイティブが一度に生成されます。

C

Midjourney向けロゴ見本帳を作る

カテゴリ「ロゴ」→業種に合ったテンプレ（SaaS企業風・カフェ・コスメなど）を選択 → 枚数と比率を入力 → 出力先「Midjourney向け」を選択 → 画像内文字「文字なし」に変更 → プロンプト更新 → コピー。

D

オリジナルフォント作字をする

カテゴリ「フォント」→「汎用テンプレ」または「Z世代向け・ポップ」を選択 → 文字（例：「あ」）・種類数・テーマを入力 → 画像内文字「文字なし」→ 背景を「透過PNG」にするため追加条件に記載 → プロンプト更新 → コピー。

E

添付画像を参照してスライドを生成する

カテゴリ「スライド」→好みのスタイルを選択 → テーマ・枚数・比率を入力 → 「添付画像の使い方」を「雰囲気と構図を活かす」に設定 → プロンプト更新 → コピー。ChatGPT Imagesに参照したいスライドを添付しながら貼り付ける。

F

テンプレをカスタマイズして保存する

テンプレを選択 → 「元テンプレを直接編集する」を開く → プロンプト本文を書き換え → 新しい {{変数名}} を追加 → 「プロンプト更新」→「TXT保存」で手元にテキストを残す。

11

よくある質問

Qテンプレを選んでも差し込み項目が出ない
A　「ヒント」カテゴリのテンプレは {{ }} 変数がなく、プロンプト本文がそのままガイドテキストになっています。差し込み項目セクションが空白のまま表示されるのは正常動作です。
Q「プロンプト更新」を押さなくても右パネルが更新される？
A　テンプレカードを切り替えた時点でプロンプトは自動更新されます。ただし差し込み項目や共通オプションを変更した後は手動で「プロンプト更新」ボタンを押す必要があります。
Q出力先を「Midjourney向け」にしたら何が変わる？
A　プロンプト末尾に Midjourney 向けのパラメータ（--ar や --v などの記法）が自動追加されます。Midjourney 以外のツールを使う場合は「ChatGPT Images」または「Nano Banana / 汎用」を選ぶことをおすすめします。
Q追加条件と差し込み項目は両方使える？
A　はい。差し込み項目はテンプレ内の変数を置換し、追加条件はプロンプト末尾に連結されます。両方入力すると、より細かい指示をAIに渡せます。
Q日本語プロンプトでも画像生成AIは理解してくれる？
A　ChatGPT Images・Nano Banana は日本語プロンプトで問題なく動作します。Midjourney は英語が推奨されているため、必要に応じて英語に翻訳してから使ってください。
Qイラストカテゴリのテンプレはキャラ画像の添付が必要？
A　テンプレ本文に「このキャラクターを…」という記載があるものは、参照したいキャラクター画像の添付が前提です。「添付画像の使い方」を「添付画像のキャラクターを維持して入れ替える」に設定してから使ってください。
Q自作のテンプレを追加できる？
A　「元テンプレを直接編集する」エリアで既存テンプレを改変して使うことはできますが、HTMLファイルに新テンプレを永続追加するにはファイルを直接編集する必要があります。ソース内の TEMPLATES 配列に同じ形式のオブジェクトを追加してください。
